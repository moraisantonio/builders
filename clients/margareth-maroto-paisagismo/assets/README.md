# Assets — Margareth Maroto Paisagismo

Pasta reservada pra tudo que a cliente for mandando. Duas subpastas:

- **`identidade-visual/`** — logotipo (de preferência SVG ou PNG em alta), manual de marca se existir, paleta de cores oficial
- **`referencias/`** — inspiração visual: print do perfil do Instagram, export/prints do board do Pinterest, fotos de projetos que a Margareth ou a equipe mandarem
  - **`referencias/landing-pages-exemplo/`** — screenshots/prints de landing pages (dela ou de outras marcas) que sirvam de referência estrutural pro primeiro teste da home. Arraste os prints direto pra cá.

## Sobre imagens coladas no chat

Imagens coladas direto na conversa (como o print do Instagram) ficam **criptografadas no Mac** — não é possível salvá-las no projeto automaticamente. O jeito de resolver:

1. **Finder:** salve a imagem (clique direito → salvar como) e arraste o arquivo pra pasta certa aqui dentro
2. **VS Code:** abra `assets/identidade-visual/` ou `assets/referencias/` no explorador e arraste o arquivo pra dentro

Assim que os arquivos existirem aqui, dá pra referenciar eles nos documentos do projeto e, mais pra frente, no próprio código do site.
